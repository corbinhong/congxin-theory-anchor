## 这是什么

从心论是一套从「心念」出发的认识论体系，共 **七条公理**，依四个层次递进：

1. **基础**：心念的点燃，心念与世界的界面（公理一、二）
2. **运作**：条件汇聚式因果，外部世界的功能定位（公理三、四）
3. **涌现**：时间、自我、自由意志、他心（公理五、六）
4. **定位**：理论自身的性质与价值来源（公理七）

公理的次序即论证的次序，每一条皆以前一条为前提，不宜跳读。
